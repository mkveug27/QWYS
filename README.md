# QWYS

**QWYS** — демонстрационное Flutter-приложение с тематическими квизами, разработанное как личный проект для практики и демонстрации навыков мобильной разработки.

## Технологический стек

| Технология | Назначение |
|---|---|
| Flutter / Dart | Разработка приложения |
| flutter_bloc | Управление состоянием |
| Dio | HTTP-запросы и работа с API |
| GetIt | Внедрение зависимостей |
| GoRouter | Навигация |
| Slang | Локализация |
| Talker | Логирование |

## Запуск проекта

**Требования:**
- Flutter SDK.
- Dart SDK.
- Android Studio или Xcode для запуска на соответствующих платформах.

**Установка зависимостей:**

```bash
flutter pub get
```

**Настройка окружения:**

Создать `.env` на основе `.env.example` и указать необходимые параметры API:

```env
BASE_URL_DEV = 
BASE_URL_PROD = 
API_KEY = 
```

Дополнительные инструкции по настройке проекта, генерации файлов и сборке доступны в [документации для разработчиков](docs/DEVELOPMENT.md).

## Статус проекта

QWYS — демонстрационный проект для портфолио. Предназначен для демонстрации технических решений, организации Flutter-приложения и практических навыков разработки.
